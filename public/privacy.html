Keyflame privacy policy

Last updated: 28 October 2026

Keyflame is a typing game for children. We built it so that it does not need, ask for, or collect personal information from anyone.

What stays on your device

Progress (rider names, dragons, lesson stars, race results and settings) is saved in your browser's own storage on your device. It is not sent to us. Rider and dragon names are picked from preset word lists, so children never type their real names. Clearing your browser data deletes this progress unless you have made a backup code.

What we do not collect

  • No names, email addresses, phone numbers, photos or locations.
  • No accounts and no sign-in.
  • No chat or messaging between players.
  • No tracking cookies or advertising identifiers set by Keyflame.

Bug reports and ideas

The game has an optional "Report a bug or idea" form. A grown-up check is shown before anything is sent. A report contains only the message typed, whether it is a bug or an idea, the game version, the screen it was sent from, a rough device description (for example "Android phone, Chrome"), and whether a keyboard or the touch screen was used. It never includes a name, account or full browser details. Anything that looks like an email address, phone number or link is removed on the device before sending. Please do not write personal information in a report. Reports are stored with our database provider, Supabase, kept only to fix bugs and improve the game, and can be deleted on request. Like any website, Supabase and our host see the IP address of the device that sends a request. It is not saved with the report, though Supabase keeps it for a short time in its own request logs.

No advertising

Keyflame shows no ads and contains no advertising code.

Supporter pack

The optional supporter pack is bought by a parent or guardian through a payment page run by our payment provider. We never see or store card details. A grown-up check is shown before the payment page opens.

After the pack is bought, the game shows a supporter code that unlocks it on other devices. The code is random letters. It is not linked to a name, email or payment, and it is kept only in your browser and in backup codes you make.

Fonts and hosting

The website is hosted on GitHub Pages, which receives standard technical information (like the IP address and browser type) needed to deliver files. The fonts are part of the game itself, so no font service is contacted.

Parents' rights

We do not collect personal information, so apart from any bug reports or ideas that were sent, nothing about a player is stored with us. To remove all Keyflame data from a device, use "Remove rider" in Settings or clear the browser's site data.

On iPads and iPhones, Safari may clear a website's saved data if it is not opened for a while. Adding Keyflame to the Home Screen and making a backup code in Settings keeps progress safe.

Contact

Questions about this policy can be raised at github.com/davidbalasa-ui/keyflame/issues.
