Keyflame privacy policy

Last updated: 28 October 2026

Keyflame is a typing game for children. We built it so that it does not need, ask for, or collect personal information from anyone.

What stays on your device

Progress (rider names, dragons, lesson stars, race results and settings) is saved in your browser's own storage on your device. It is not sent to us. Rider and dragon names are picked from preset word lists, so children never type their real names. Clearing your browser data deletes this progress unless you have made a backup code.

What we do not collect

  • No names, email addresses, phone numbers, photos or locations.
  • No accounts and no sign-in.
  • No chat or messaging between players.
  • No tracking cookies or advertising identifiers set by Keyflame.

Bug reports and ideas

The game has an optional "Report a bug or idea" form. A grown-up check is shown before anything is sent. A report contains only the message typed, whether it is a bug or an idea, the game version, the screen it was sent from, a rough device description (for example "Android phone, Chrome"), and whether a keyboard or the touch screen was used. It never includes a name, account or full browser details. Anything that looks like an email address, phone number or link is removed on the device before sending. Please do not write personal information in a report. Reports are stored with our database provider, Supabase, kept only to fix bugs and improve the game, and can be deleted on request. Like any website, Supabase and our host see the IP address of the device that sends a request. It is not saved with the report, though Supabase keeps it for a short time in its own request logs.

Classroom mode

A teacher can make a class, which gives a six-letter class code. No sign-up is needed, and the class is not linked to a school, a teacher's name or an email. The teacher gives each student a badge number, and students join with the class code and their badge number. Players in a class can race each other live. While a player is in a class, the other devices in that class see their rider name, which is made from preset words, their dragon's look, and their race progress. A rider name that is not made from the preset words shows as "Rider". There is no chat.

What is stored with our database provider, Supabase, for a class: the class code; each badge number with the rider name last used with it; for each lesson and race finished while in the class, which lesson it was and its stars, speed, accuracy, place, number of racers, whether a touch screen was used, and the time; and a scrambled form of a random key from each device that joins as a badge, so a mistyped badge number can't add results to a classmate. Anyone with the class code can see the class board of best race speeds. Only the device that made the class, or a teacher who opens the class with its teacher password, can see each badge's progress.

Student names. If the teacher types student names, they stay on the teacher's device. To keep them safe if the device's saved data is cleared, the list is locked on the teacher's device with the teacher password before it is backed up, so we store only a locked copy that we cannot read. We never see the password. If the teacher forgets the password, the locked copy can't be opened by anyone, including us; the badge numbers and results stay, and the teacher can type the names again from the printed class sheet or a backup file. Backup files and printed sheets are kept by the teacher and never sent to us.

The teacher can remove a student, which deletes that badge's lessons and races, give the class a new code, and clear the board. To leave a class, a player taps "Leave class". A class that is not used for a year is deleted along with everything saved for it. Live race messages pass through Supabase and are not stored.

No advertising

Keyflame shows no ads and contains no advertising code.

Supporter pack

The optional supporter pack is bought by a parent or guardian through a payment page run by our payment provider. We never see or store card details. A grown-up check is shown before the payment page opens.

After the pack is bought, the game shows a supporter code that unlocks it on other devices. The code is random letters. It is not linked to a name, email or payment, and it is kept only in your browser and in backup codes you make.

Fonts and hosting

The website is hosted on GitHub Pages, which receives standard technical information (like the IP address and browser type) needed to deliver files. The fonts are part of the game itself, so no font service is contacted.

Parents' rights

We do not collect personal information, so apart from any bug reports or ideas that were sent and class results, nothing about a player is stored with us. To remove all Keyflame data from a device, use "Remove rider" in Settings or clear the browser's site data.

On iPads and iPhones, Safari may clear a website's saved data if it is not opened for a while. Adding Keyflame to the Home Screen and making a backup code in Settings keeps progress safe.

Contact

Questions about this policy can be raised at github.com/davidbalasa-ui/keyflame/issues.
