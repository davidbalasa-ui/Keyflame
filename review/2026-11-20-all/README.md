# Keyflame: every screen for a full review (2026-11-20)

Taken from the live code (main after PR #66, same as keyflame.org) in Chromium with a scripted player.
The bot types real keys at about 80 WPM with no mistakes, so speeds and "faster than usual" rewards are bot numbers, not kid numbers.
Typing real keys also tells the game a hardware keyboard is in use, so on phone/iPad the on-screen tap keyboard can look unpinned or hidden. That is the bot, not a bug.
