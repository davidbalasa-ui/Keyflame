# First hatch and adaptive races — review, 2026-11-24

Reviewed `progress.ts`, `eggMeter.ts`, `typing.ts`, `sentences.ts`, `tests/adaptive.test.ts` on main. Static review; screenshot packet and live phone not verified. No claimed runtime tests.

1. **High — race adaptation is not a three-race mastery test.** `raceForm` filters out low-accuracy races *before* taking 3, so one old fast race opens letters immediately, and repeated bad recent races do not displace that result. The tests explicitly permit one qualifying race. A kid with fast home-row skill can jump into unseen letters and stay stuck despite poor results. Use the last three same-input races, require a minimum sample count and recent accuracy; allow a clearly marked optional fast-typist placement route. Step down on two recent struggling races and add hysteresis so tiers don't bounce. Test old good + recent bad, one lucky short race, first top-row race and separate touch/physical keyboard. 20/28 WPM are reasonable initial tuning hypotheses, not evidence of letter mastery. Prefer per-row or per-key familiarity and guided practice for a beginner; don't change lesson order. Touch 14/19.6 equivalents need separate calibration.
2. **High — accuracy is neither position accuracy nor raw keystroke accuracy in strict mode.** `accuracy()` uses correct/(correct+errors) with errors once per position. In strict mode all positions eventually count correct, so 100 chars with 9 missed positions yields 91.74%, rather than 91% first-try; 100 chars with every position missed still shows 50%. Relaxed mode's denominator is positions. Make first-try accuracy use `(attemptedPositions - missedPositions)/attemptedPositions` consistently, retain wrong-press count separately if useful; update UI wording, 92% adaptation gate and tests together, or explicitly document existing metric and don't compare strict/relaxed directly. Test a repeated miss, all wrong and partially completed session. Keep per-wrong-press race penalty.
3. **Medium — meter can promise unbanked warmth.** `eggMeter` displays `nest.warmth + correct`; applySession banks warmth when session finishes. If leaving early, meter may say Ready then revert. Verify quitting, crash/reload, and early ready mid-race. Either persist earned warmth safely exactly once or label pending progress and clearly say finish to hatch, with result reflecting committed amount. Avoid double-credit on resume.
4. **Medium — first hatch 120 is a sensible starting target.** At 10 WPM ~50 correct characters/minute, 120 is ~2.4 minutes active typing (not elapsed screen time); at 5 WPM ~4.8 minutes plus menus and errors. Keep 120; don't increase until measured with 7-year-olds. Make acceptance an actual L1 + first race using generated lengths and real duration, rather than current test injecting 120 keys into one race with inconsistent 12 WPM/60s. Include a slow child, incomplete lesson and existing 120+ warmth migration.
5. **Medium — phone header check required.** Egg meter's short label and visual bar are good; aria label supplies units. Ensure no overlap with Flame dash, timer, keyboard mode or long translations at 320/390 and large-text. Give a 120-to-Ready state and no layout jump when digit count changes. Prefer label 'N keys' when space permits; don't steal typing area. This is a proposed visual test, not a screenshot finding.
6. **Low — home-row lines are safe but some are artificial.** 'a gala has salads', 'a hall has glass', 'half a glass falls', 'all dads had a gala', 'dad has alfalfa salad' are odd or challenging vocabulary for 7-year-olds. Prefer simple familiar actions within allowed alphabet, e.g. 'dad has a salad', 'a lad has a glass', 'dad adds salsa', 'all lads dash'. Avoid repeating the same dad/lad formula in one race; use weighted variety and validate every line against learned keys. No inappropriate text found in the displayed home-row bank. Keep manual sentence authoring and avoid random letter combinations.

Verdict: ship the shorter first-hatch direction; correct the adaptation window and accuracy semantics, then verify the header and banked warmth in live mobile play.
